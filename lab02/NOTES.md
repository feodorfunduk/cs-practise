Создана папка lab02 и notes.ms
git - для работы с удаленными репозиториями через терминал
github - облачный хост репозиториев
git status  - показывает текущее состояние рабочей директории и индекса
git diff - показываеи разницу между рабочей директорией и индексом
git diff --staged - показывает различия между индексом и последним коммитом
Ветка - указатель на определенный коммит, при создании нового коммита указатель ветки сдвигается на этот новый коммит. Слияние веток это обьединение изменений из одной ветки в другую
